# YouTube Playlist Player (Rust / Tauri v2)

プレイリストを取得 → アプリ内で並べ替え・再生 → 必要なら YouTube へ反映（Push）するデスクトップアプリ。
バックエンドは Rust、画面は `web/`（HTML/JS）を OS 標準の WebView2 で表示する。

## セットアップ
1. Google Cloud Console で YouTube Data API v3 を有効化し、OAuth クライアント（種類: デスクトップアプリ）を作成。
   アプリの「設定」から JSON を取り込むか、`client_secret.json` として exe と同じフォルダ（開発時はプロジェクト直下）に置く。
2. `build.ps1`（または `cd src-tauri && cargo build --release`）
3. `youtube-playlist-player.exe` を起動（初回のみブラウザで認可。以後 `token.json` で自動更新）

## 主な機能
- **再生**: ビデオ／音楽モード、再生速度の変更とリセット、「この1本だけ再生」。URL 欄に動画の URL を入れると、登録せずに再生だけできる（再度「追加」で保存先リストを選択）。
- **リスト操作**: 左ペインのツリーで展開・ドラッグ並べ替え、リスト名のダブルクリックまたは右クリック「編集」で別ウィンドウ（複数可）。ウィンドウ間のドラッグで動画を移動、右クリック「リストに保存…」で複数リストへ保存・新規リスト作成。
- **リストの取り込み**: 別リストの動画を丸ごと取り込む（コピー。右クリック、またはリスト名のドラッグ）。
- **検索・並べ替え**: リスト名の右クリック、または編集ウィンドウの「検索・並べ替え」ポップアップ。タイトル／チャンネル名で検索、名前順・チャンネル順で並べ替え。
- **メモ**: 画面下部。Enter で再生位置のタイムスタンプ付きリンクを追加、自由記述も可。
- **ウィンドウ位置・大きさ**: `window.ini` に保存・復元。

## Push（YouTube への反映）
並べ替え・追加・削除・新規リストの作成は、まず手元だけに溜まり、Push で YouTube に反映する。
- Push の前に、件数・概算コスト・今日の残りクォータを表示する。
- 1日の上限（10,000 ユニット）を超える場合は、次のどちらかを選べる。
  - **別日に行う**: 今日の残り分だけ反映し、残りを `deferred.json` に保存。次回起動時に続きを案内する。
  - **常駐して最後まで**: 上限に達したらウィンドウを最小化して待機し、回復後（太平洋時間 0 時）に自動で再開する。
- 使用量はこのアプリの消費分の推定（`quota.json`）。実際に上限に達した場合は API のエラーで検知する。

## クォータ
- 並べ替え・再生・検索は消費 0。取得は 1 ユニット/50 件。
- 書き戻し（作成・追加・削除・位置変更）は 50 ユニット/件。サーバー側の並びをシミュレートし、必要な更新だけ実行する。
- 書き戻し対象は「手動並べ替え」設定のプレイリストであること。

## 開発
- テスト: `cd src-tauri && cargo test`
- 保存ファイル（`token.json` / `window.ini` / `quota.json` / `deferred.json`）は認証情報と同じフォルダに作られる。リポジトリには含めない。
