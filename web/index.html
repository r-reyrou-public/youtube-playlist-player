YouTube API 認証情報
自分の OAuth クライアントを使う場合の取得手順（通常は不要）
  1. API の有効化ページ を開き、プロジェクトを選択（なければ新規作成）して「有効にする」。
    プロジェクト作成と YouTube Data API v3 の有効化が 1 回で済みます。
  2. OAuth 同意画面 を開き、ユーザーの種類は外部、アプリ名とメールアドレスを入力して保存。テストユーザーに自分の Google アカウントを追加します。
    テスト状態のままで構いません（その場合、認可は 7 日で失効するので再認可が必要です）。
  3. 認証情報ページ で「認証情報を作成」→「OAuth クライアント ID」→ 種類「デスクトップ アプリ」で作成。
    作成直後のダイアログの「JSON をダウンロード」を押します。（「API キー」「サービス アカウント」は不要です）
  4. 上の「ダウンロード済みJSONから自動設定」を押すだけで完了です（別の場所に保存した場合は「JSONファイルを選択…」）。
  5. メイン画面の「マイリスト取得」を押すとブラウザが開きます。「このアプリは Google で確認されていません」と出たら詳細 → 続行で許可します。以後は自動でログインされます。

JSON のシークレットが手元にない場合は、認証情報ページでクライアント名をクリックし「シークレットを追加」で発行し直してください。

API の無料枠は 1 日 10,000 ユニットです。一覧取得は 1 ユニット/50 件、並び順の書き戻しは 50 ユニット/件です。
