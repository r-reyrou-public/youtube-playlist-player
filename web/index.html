YouTube API 認証情報
取得手順（クリックで表示）
  1. Google Cloud Console（プロジェクト作成） を開いて Google アカウントでログインし、新しいプロジェクトを作成します。
  2. YouTube Data API v3 のページ を開き、有効にするを押します（先ほどのプロジェクトが選択されていることを確認）。
  3. OAuth 同意画面 を開き、ユーザーの種類は外部、アプリ名とメールアドレスを入力して保存します。
    「テストユーザー」に自分の Google アカウントを追加します（公開しない場合はテスト状態のままで構いません。ただしテスト状態では認可が 7 日で失効するため、その際は再認可が必要です）。
  4. 認証情報ページ で「認証情報を作成」→「OAuth クライアント ID」を選び、アプリケーションの種類にデスクトップ アプリを選んで作成します。
    「API キー」「サービス アカウント」は不要です（選ぶと API キーの作成画面が開きます。その場合はキャンセルして、OAuth クライアント ID を選び直してください）。
  5. 作成済みなら、一覧の「デスクトップ クライアント」名をクリックして詳細を開き、クライアント ID とクライアント シークレットを上の欄に入力して「保存」します。シークレットが表示されない場合は、作成時にダウンロードした JSON を使うか、詳細画面の「シークレットを追加」で発行し直してください（client_secret.json として自動保存されます。JSON をダウンロードして同じ場所に置いても構いません）。
  6. メイン画面の「マイリスト取得」を押すとブラウザが開きます。アカウントを選び、「このアプリは Google で確認されていません」と出たら詳細 → 続行で許可してください。以後は自動でログインされます。

API の無料枠は 1 日 10,000 ユニットです。一覧取得は 1 ユニット/50 件、並び順の書き戻しは 50 ユニット/件です。
