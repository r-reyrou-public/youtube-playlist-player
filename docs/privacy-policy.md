# プライバシーポリシー / Privacy Policy

最終更新日 / Last updated: 2026-10-24

YouTube Playlist Player（以下「本アプリ」）は、利用者のパソコン上で動作するデスクトップアプリです。

## 取得する情報
本アプリは、利用者が Google アカウントでログインして許可した場合に、YouTube Data API を通じて次の情報にアクセスします。
- 利用者の YouTube プレイリストの一覧（タイトル、動画数）
- プレイリストに含まれる動画の情報（動画ID、タイトル、サムネイル、並び順）

## 利用目的
- 取得したプレイリストをアプリ上に表示し、再生すること。
- 利用者が行った編集（並べ替え、動画のリストへの追加・リストからの削除、新しいリストの作成）を、利用者の操作（Push）によって YouTube 上のプレイリストへ反映すること。リスト自体の削除や、動画のアップロード・削除は行いません。

上記以外の目的には使用しません。

## 保存と共有
- 取得した情報とログイン情報（アクセストークン、リフレッシュトークン）は、**利用者のパソコン内にのみ**保存されます（`token.json`）。
- 開発者を含む第三者のサーバーへ送信・共有・販売することはありません。
- 広告、アクセス解析、トラッキングは行いません。

## Google API サービスのユーザーデータポリシー
本アプリによる Google API から受け取った情報の使用および他のアプリへの転送は、限定的な使用の要件を含め、
[Google API サービスのユーザーデータポリシー](https://developers.google.com/terms/api-services-user-data-policy)に準拠します。

The use of information received from Google APIs will adhere to the
[Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy),
including the Limited Use requirements.

## データの削除・アクセス権の取り消し
- アプリ内の「認可をリセット」、または保存先の `token.json` を削除すると、保存されたログイン情報が消えます。
- Google アカウントの「[サードパーティのアクセス](https://myaccount.google.com/permissions)」から、いつでも本アプリのアクセス権を取り消せます。
- YouTube の利用には [YouTube 利用規約](https://www.youtube.com/t/terms)が適用されます。
